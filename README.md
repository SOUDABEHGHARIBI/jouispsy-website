# JOUISPSY Psychotherapy website

Static, responsive website for GitHub Pages.

Upload the contents of this folder to the root of the `jouispsy-website` repository. Then enable GitHub Pages under Settings → Pages → Deploy from a branch → main / (root). Set custom domain to `jouispsy.ca` after configuring DNS at Namecheap.

The `CNAME` file is included but DNS records must still be configured.

No booking or client intake form is implemented.
